## **Topics Covered**

* **Focus:** Digital Logic and Basic Software
* **Chapter 1: What is an Operating System?:** The role of mediator between humans and hardware.
* **Chapter 2: The Kernel:** The Invisible Heart (User Space vs. Kernel Space).
* **Chapter 3: Process Management:** How the OS divides CPU time (Scheduling & Context Switching).
* **Chapter 4: Memory Management:** Allocation, protection and Garbage Collection.
* **Chapter 5: File System (NTFS, ext4, APFS):** How we organize bits on the disk.
* **Chapter 6: Drivers and Interrupts:** How the OS communicates with peripherals.
