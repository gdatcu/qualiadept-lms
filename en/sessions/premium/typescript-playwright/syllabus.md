# **QA Automation Bootcamp: De la Zero la CI/CD cu TypeScript & Playwright**

| Format: Live Sessions / Technical Mentoring Total duration: 50 hours Structure: 20 sessions x 2.5 hours/session Level: Beginner / Intermediate (Manual QA to QA Automation) |
| :---- |

## **🎯 Program Objectives**

This program is designed to transform manual test engineers into full-fledged automation engineers. Unlike traditional courses, students will first learn **to build a web application** to understand how it works "under the hood", and then they will build an **E2E testing framework from scratch**, integrated into a CI/CD pipeline.

## **📅 Curriculum Structure (Syllabus)**

### **Module 1: Web Architecture & Fundamentals (HTML5 & CSS3)**

*2 Sessions | 5 Live Hours*

> * **Session 1: Web architecture and DOM structure.** How the internet and browsers work. Introduction to HTML, semantic tags and attributes. Creating the visual skeleton for the course application.  
> * **Session 2: Modern CSS and selectors.** Classes, IDs, hierarchies and layout (basic Flexbox). **Focus QA:** Mastering CSS selectors (custom attributes, pseudo-classes) – the absolute foundation for identifying elements in test scripts.

### **Module 2: Modern & Asynchronous JavaScript**

*4 Sessions | 10 Live Hours*

> * **Session 3: Basics of JS programming.** Variables (let, const), data types, control structures and functions (including arrow functions).  
> * **Session 4: DOM manipulation.** Event listeners (addEventListener), user interaction with the page, dynamic addition and deletion of web elements.  
> * **Session 5: Asynchronous JavaScript.** The concept of Event Loop. Promises, async/await and client-server communication using the Fetch API.  
> * **Session 6: Practical Workshop.** Finalizing the logic of our web application (e.g. a functional Kanban board or Task Tracker) which will become the "subject" of our tests.

### **Module 3: Switching to TypeScript**

*2 Sessions | 5 Live Hours*

> * **Session 7: Static typing.** Why Playwright and the industry use TypeScript. tsconfig.json configuration. Primitive types, any, unknown, void.  
> * **Session 8: Advanced structures in TS.** Interfaces, Custom Types, and Classes. Refactoring part of your application code or writing test utility functions using strictly TypeScript.

### **Module 4: Playwright Fundamentals**

*2 Sessions | 5 Live Hours*

> * **Session 9: Setup and Architecture.** Playwright vs. Selenium/Cypress. Installation, the playwright.config.ts file, using the CLI, and generating code through Playwright Codegen.  
> * **Session 10: Navigation and basic actions.** First E2E test written manually on the web application we built (click, fill, check, select). Using the Playwright Inspector.

### **Module 5: Localization Strategies and Assertions**

*2 Sessions | 5 Live Hours*

> * **Session 11: The Philosophy of Locators.** Using getByRole, getByText, getByTestId. How to avoid fragile selectors (long XPaths). The concept of auto-waiting in Playwright.  
> * **Session 12: Web-First Assertions (expect).** Status, visibility and content validations. Handling complex elements: iFrames, multiple windows (Pop-ups) and native browser alerts.

### **Module 6: Premium Architecture & Scalability**

*3 Sessions | 7.5 Live Hours*

> * **Session 13: Page Object Model (POM).** Structuring the framework for scalability and maintainability. Creating page classes in TypeScript.  
> * **Session 14: Custom Fixtures & Data-Driven.** Building your own "fixtures" to simplify test setup. Running the same test with multiple datasets extracted from JSON files.  
> * **Session 15: Global Setup & Authentication State.** Optimize tests by authenticating only once (saving the session/cookies) and reusing it, saving valuable execution time.

### **Module 7: Network Interception & Advanced Testing**

*2 Sessions | 5 Live Hours*

> * **Session 16: API Mocking.** Intercepting HTTP requests. How to test the interface by isolating it from the backend (e.g. simulating a 500 Internal Server Error, modifying API responses in real time).  
> * **Session 17: Advanced Reporting and Debugging.** Handling flaky tests, retries. Analyzing HTML reports, using the step-by-step Trace Viewer, screenshots and video recording of failures.

### **Module 8: CI/CD with GitHub Actions**

*2 Sessions | 5 Live Hours*

> * **Session 18: Git & GitHub Basics.** Version control, commits, pushes, creating Pull Requests. Introduction to automation and YAML syntax.  
> * **Session 19: Building the Pipeline.** Creating .github/workflows/playwright.yml. Installing the environment in Ubuntu containers, running "headless" tests on every push and automatically publishing artifacts (test reports).

### **Module 9: Completion & Demo Day**

*1 Session | 2.5 Hours Live*

> * **Session 20: Project presentation.** Each student will present their live portfolio (application, test framework and pipeline on GitHub). Live Code Review session, final conclusions and tips for technical interviews.
