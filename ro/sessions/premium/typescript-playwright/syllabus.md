# **QA Automation Bootcamp: De la Zero la CI/CD cu TypeScript & Playwright**

| Format: Sesiuni Live / Mentorat tehnic  Durată totală: 50 de ore  Structură: 20 de sesiuni x 2.5 ore/sesiune  Nivel: Începător / Intermediar (QA Manual spre QA Automation) |
| :---- |

## **🎯 Obiectivele Programului**

Acest program este conceput pentru a transforma inginerii de testare manuală în ingineri de automatizare compleți. Spre deosebire de cursurile clasice, cursanții vor învăța mai întâi **să construiască o aplicație web** pentru a înțelege cum funcționează „sub capotă”, iar apoi vor construi un **framework de testare E2E de la zero**, integrat într-un pipeline de CI/CD.

## **📅 Structura Curriculei (Syllabus)**

### **Modulul 1: Web Architecture & Fundamente (HTML5 & CSS3)**

*2 Sesiuni | 5 Ore Live*

> * **Sesiunea 1: Arhitectura web și structura DOM-ului.** Cum funcționează internetul și browserele. Introducere în HTML, tag-uri semantice și atribute. Crearea scheletului vizual pentru aplicația cursului.  
> * **Sesiunea 2: CSS modern și selectoare.** Clase, ID-uri, ierarhii și layout (Flexbox de bază). **Focus QA:** Stăpânirea selectoarelor CSS (atribute custom, pseudo-clase) – fundamentul absolut pentru identificarea elementelor în scripturile de testare.

### **Modulul 2: JavaScript Modern & Asincron**

*4 Sesiuni | 10 Ore Live*

> * **Sesiunea 3: Bazele programării în JS.** Variabile (let, const), tipuri de date, structuri de control și funcții (inclusiv arrow functions).  
> * **Sesiunea 4: Manipularea DOM-ului.** Ascultători de evenimente (addEventListener), interacțiunea utilizatorului cu pagina, adăugarea și ștergerea dinamică a elementelor web.  
> * **Sesiunea 5: JavaScript Asincron.** Conceptul de Event Loop. Promises, async/await și comunicarea client-server folosind Fetch API.  
> * **Sesiunea 6: Workshop Practic.** Finalizarea logicii aplicației noastre web (ex: un panou de tip Kanban sau Task Tracker funcțional) care va deveni "subiectul" testelor noastre.

### **Modulul 3: Trecerea la TypeScript**

*2 Sesiuni | 5 Ore Live*

> * **Sesiunea 7: Tipizarea statică.** De ce Playwright și industria folosesc TypeScript. Configurare tsconfig.json. Tipuri primitive, any, unknown, void.  
> * **Sesiunea 8: Structuri avansate în TS.** Interfețe (Interfaces), Tipuri Custom (Types) și Clase. Refactorizarea unei părți din codul aplicației sau scrierea de funcții utilitare de testare folosind strict TypeScript.

### **Modulul 4: Playwright Fundamentals**

*2 Sesiuni | 5 Ore Live*

> * **Sesiunea 9: Setup și Arhitectură.** Playwright vs. Selenium/Cypress. Instalare, fișierul playwright.config.ts, utilizarea CLI-ului și generarea de cod prin Playwright Codegen.  
> * **Sesiunea 10: Navigare și acțiuni de bază.** Primul test E2E scris manual pe aplicația web construită de noi (click, fill, check, select). Utilizarea Inspectorului Playwright.

### **Modulul 5: Strategii de Localizare și Asertări**

*2 Sesiuni | 5 Ore Live*

> * **Sesiunea 11: Filosofia Localizatorilor (Locators).** Utilizarea getByRole, getByText, getByTestId. Cum evităm selectoarele fragile (XPath-uri lungi). Conceptul de auto-waiting în Playwright.  
> * **Sesiunea 12: Web-First Assertions (expect).** Validări de stare, vizibilitate și conținut. Manipularea elementelor complexe: iFrames, ferestre multiple (Pop-ups) și alerte native din browser.

### **Modulul 6: Arhitectură Premium & Scalabilitate**

*3 Sesiuni | 7.5 Ore Live*

> * **Sesiunea 13: Page Object Model (POM).** Structurarea framework-ului pentru scalabilitate și mentenabilitate. Crearea claselor de pagină în TypeScript.  
> * **Sesiunea 14: Custom Fixtures & Data-Driven.** Construirea propriilor "fixtures" pentru a simplifica setup-ul testelor. Rularea aceluiași test cu multiple seturi de date extrase din fișiere JSON.  
> * **Sesiunea 15: Global Setup & Authentication State.** Optimizarea testelor prin autentificarea o singură dată (salvarea sesiunii/cookies) și reutilizarea acesteia, economisind timp prețios de execuție.

### **Modulul 7: Interceptare Rețea & Advanced Testing**

*2 Sesiuni | 5 Ore Live*

> * **Sesiunea 16: API Mocking.** Interceptarea request-urilor HTTP. Cum testăm interfața izolând-o de backend (ex: simularea erorii 500 Internal Server Error, modificarea răspunsurilor API în timp real).  
> * **Sesiunea 17: Raportare și Debugging avansat.** Gestionarea testelor instabile (flaky tests), retry-uri. Analiza rapoartelor HTML, utilizarea Trace Viewer-ului pas-cu-pas, capturi de ecran și înregistrare video la eșec.

### **Modulul 8: CI/CD cu GitHub Actions**

*2 Sesiuni | 5 Ore Live*

> * **Sesiunea 18: Git & GitHub Basics.** Version control, commit-uri, push, crearea de Pull Requests. Introducere în automatizări și sintaxa YAML.  
> * **Sesiunea 19: Construirea Pipeline-ului.** Crearea .github/workflows/playwright.yml. Instalarea mediului în containere Ubuntu, rularea testelor "headless" la fiecare push și publicarea automată a artefactelor (rapoarte de testare).

### **Modulul 9: Finalizare & Demo Day**

*1 Sesiune | 2.5 Ore Live*

> * **Sesiunea 20: Prezentarea proiectelor.** Fiecare cursant își va prezenta portofoliul live (aplicația, framework-ul de teste și pipeline-ul din GitHub). Sesiune de Live Code Review, concluzii finale și sfaturi pentru interviurile tehnice.

## **🏆 Livrabilele Finale ale Cursanților (Portofoliu)**

| 💰 La sfârșitul programului, cursanții vor avea un repository public pe GitHub cu greutate la angajare, conținând: Aplicația Web: Frontend funcțional creat cu HTML, CSS și TS. Framework-ul E2E: Suita de teste Playwright \+ TypeScript structurată folosind Page Object Model. Pipeline-ul CI/CD: Fișierul GitHub Actions care dovedește capacitatea de a integra testele în fluxul de dezvoltare continuă. |
