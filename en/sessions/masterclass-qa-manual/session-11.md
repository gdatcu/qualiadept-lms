## **Topics Covered**

* **Focus:** POST, PUT, DELETE methods, Environment Variables & Advanced Scripting
* **Complex requests:** Sending, updating, and removing server data using POST, PUT, and DELETE HTTP methods.
* **Test automation in Postman:** Using the *Tests* tab to author automated assertions for status codes, headers, body structures, and response times via JavaScript snippets.
* **Environment management in Postman:** Configuring global, collection, and environment variables to parameterize and reuse requests across multiple stages.
* **Parsing JSON responses & Data Chaining:** Extracting dynamic response data (e.g., auth tokens, generated entity IDs) and passing them forward into subsequent requests automatically.
