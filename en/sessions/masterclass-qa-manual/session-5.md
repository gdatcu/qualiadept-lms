## **Topics Covered**

* **Focus:** Boundary Value Analysis, Equivalence Partitioning and decision tables
* **Equivalence Partitioning (EP) and Boundary Value Analysis (BVA):** Optimizing the number of tests by selecting representative equivalence classes.
* **State Transition Testing:** Testing the behavior of state-and-transition-based systems.
* **Decision Tables:** Logic behind testing complex business rules.
* **Applied Story:** How to test an ATM using decision tables.
